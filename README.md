## ✨ Overview

**E-Commerce Automation Framework** is an end-to-end web automation testing project built with **Python, Selenium WebDriver and Pytest**.

The framework automates a complete customer shopping journey on the **TutorialsNinja OpenCart Demo Store**, covering everything from account registration and login to product search, cart management, validation and logout.

The project follows the **Page Object Model (POM)** architecture to keep test logic clean, reusable and maintainable.

> **Goal:** Build a scalable automation framework that simulates a real-world e-commerce testing workflow rather than isolated browser scripts.
